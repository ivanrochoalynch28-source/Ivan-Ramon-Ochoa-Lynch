# Ivan Ramón Ochoa Lynch

Cinematic Momentum portfolio, published with GitHub Pages from the root of `main`.

The site uses static HTML, CSS, JavaScript, local fonts, and the original photography
and writing. No build step is required. Internal URLs include the project base path
`/Ivan-Ramon-Ochoa-Lynch/`.

The current game theory revision is served from the primary PDF path and the legacy
`cheating-beliefs-curved-grading-github.pdf` alias. Both contain the same supplied
revision, as do the rendered page previews and reading view.
